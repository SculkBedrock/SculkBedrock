# sc_console —— 独立命令行控制台

独立进程的终端 GUI（扁平极简风）：两行标题条 + 日志流 + 右侧在线玩家面板 + 补全列表 + 五行输入框 + 状态行。

## 布局

```text
⬢ SculkBedrock <核心版本>                        CPU x.x%
<版本包标签>                                          MEM x.x MB
22:01:11 INFO  服务端启动完成 ...        │在线玩家(2)
...                                      │Steve
  stop     Stops the server              │Alex

   ❯  say hello _
   <版本包标签>（输入框左下角脚注；庆祝时变为 STARTUP）
TAB 补全 · ...                              补全:static
```

- 标题两行：左 服务端版本/一言，右 本进程 CPU 占用/内存占用
  （控制台线程本地采样，1 秒一次，只采本进程；
  CPU 归一化到整机容量 0–100%，永不超 100%；
  macOS 内存取与活动监视器同口径的 `phys_footprint`，其他平台取 RSS）；
  一言由桥接层后台线程从 `https://v1.hitokoto.cn/?c=f` 获取，
  启动时同步拉取一次（1 秒超时），首帧即正确、无闪变，失败用内置兜底；
- 输入框五行：首行留白 + 三行折行编辑（超长自动折行 + 跟随光标）+ 末行版本脚注；
  内容缩进 3 格，`❯` 为淡蓝色、后空 2 格（不贴窗口边缘、不贴文本）；
  占位提示为比底色略白的灰色；
- 日志支持键盘（PgUp/PgDn）与鼠标滚轮滚动；**超长日志自动折行**
  （无缩进续行，CJK 不劈半，单字超宽独占一行溢出），滚动/回看按可视行推进，
  落点在行中部时锚定该行首行；拖选列号按全局列折算，复制仍走整行原文。
- **右侧在线玩家面板**（独立于日志区右方，不与标题栏/输入框重叠，暗灰竖线融合）：
  首行 `在线玩家(N)` + 玩家名列表（超长截断），空服显示占位；
  底色取比标题/输入框更深一度的灰，视觉上独立成块；
  开场时与底条伸展并行、自右边缘向左滑入 dock（日志区保持最终宽度，无 reflow）；
  数据由宿主每 tick 推送（`DisplayName` 快照，进出服刷新）；
  终端窄于 70 列时自动隐藏，日志独占整宽；面板区点击无操作。
- **回看锚定**：回看时视口锚定在日志的**全局序号**（`ScrollView::Frozen`），
  **新日志不顶动视图**（环形缓冲淘汰也不顶动；锚定行被淘汰则钳到最顶）；
  滚到最顶继续滚不累积计数（往回滚立即响应），滚到底自动切回跟随。
  输入框正上方那一行同时给出：居中"按 Esc 回到底部" + 右对齐"▼新增N条日志"
  （N = 回看期间新到达、**且还没滚进视口**的条数：冻结水位排除翻过的旧行，
  视口内的新增随滚动逐步扣减，滚到底为 0 → 徽标消失；
  有补全弹窗时整行让位，点击该行 = 回到底部）。
  `Esc` 优先级：关弹窗 → 回到底部（保留输入行）→ 清空行。
- **拖选复制**（Codex 式）：日志区按住左键拖选（反白跟随），松开即自动复制，
  无需按键；点输入框任意位置即定位光标、无需切换模式。
  复制成功后输入框首行右上角显示"已复制 N 个字符到剪贴板"
  （灰蓝 slate-400，暗端 RGB 平滑插值，前 250ms 渐显、后 400ms 渐隐，共存续 2.5s）。
  剪贴板后端零第三方依赖：macOS `pbcopy` → Linux `wl-copy`/`xclip`/`xsel`
  → Windows `clip` → 都不可用则 OSC 52 直写终端（SSH 穿透）。

## 启动动效（`ServerPhase`，宿主经 `set_server_running()` 推进）

- **欢迎屏**（默认开，仅 GUI）：全屏 logo + 流光背景，首次启动按任意键后进入
  语言选择（语言栏在左：`↑↓/k/j` 移动回绕、`1-9` 直跳、`Enter/空格` 确认、
  `Esc` 回退、`Ctrl+C` 直接进入），后续启动跳过按键与选择、播完动画自动进入。
  左上角 logo 取 cfonts tiny 字形（`SCULK BEDROCK` 右缀金色 `ALPHA`，
  下方淡蓝色版本号 `1.0.0`，含窄字形按实测宽度排版），
  右缀金色 `ALPHA` 带循环金色扫光（与提示语错峰）；
  左下 `#87A5F8` → 右上 `#FDFBFE` 对角渐变（纯文字，无外发光无衬底）；
  背景 3 团深蓝高斯模糊光斑（直径统一为视口宽高和的一半，分居左/中/右三区，
  深浅占比约 1:1），自视口外缓动聚集到随机落点后随机漂移（略微超出、永不脱离），
  选择器打开后三团向视口右侧滑聚（左侧让给选项栏，600ms 缓动），
  模糊底色恒为 `#0A1026`（RGB 连续，真彩直出，约 30fps——整屏真彩 60fps
  约 2–3MB/s 会淹没软件终端模拟器的输入，见下“按键延迟”）；
  下方居中英文提示（半透明深蓝框，整宽高 3 格），1800ms 周期内 600ms
  自左向右扫光后离场；确认/自动进入后光斑沿径向加速飞出、背景约 600ms 渐隐
  （期间再按键直接跳过），随后进入控制台。
- **语言**（`en-US` / `zh-CN`，默认 `en-US`，控制台与服务端同源）：
  欢迎屏文案走项目 `rust-i18n`（`sc_console/locales/*.yml` 的 `tui.*` 键，
  与 `sc_log` 同版本同约定，`%{n}` / `%{v}` 原生插值，缺键回退 en-US），
  从不在控制台线程里拼表；语言 id 唯一真相源是 `server_properties.toml`
  的 `[server] language`（控制台线程不解析不改写宿主配置）。
  - 首次启动：选择器确认后，控制台线程只写空标记 `.sc_initialled`
    （工作目录，删掉可重选）并把选择经句柄交给宿主；宿主在欢迎门之后、
    `init_properties` 加载之前，把 `[server] language` 与
    `[server] enable_hitokoto` 原地改写（逐行手术，注释/顺序/格式逐字节
    保留，缺键则插到 `[server]` 头下），再 `set_locale` + `SCULK_LOCALE`，
    本轮日志即生效；若配置文件缺失则仅本轮生效并告警。
  - 选择器附带一言复选框：仅中文高亮时出现在视口右侧（`←→` 在语言栏与
    复选框之间定向移动焦点，框上 `空格`/`回车` 打钩，栏上 `回车` 确认），
    默认关闭；英文确认强制关闭。确认值经同一句柄交宿主落盘。
  - 一言开关真相源也是 `server.properties`（`[server] enable_hitokoto`，
    默认关闭）：宿主在欢迎门之后决定是否拉取一言（跳过则无 API 请求、
    无轮换线程、标题行为空）。控制台线程不存任何开关状态。
  - 已选过（标记存在）：直接读配置语言渲染，无按键无选择，动画播完自动进入。
  - `SC_CONSOLE_LANG` 环境变量可覆盖本次语言（不写标记不改文件，自动化用）；
    加新语言 = `locales/{code}.yml` 翻全 + `SUPPORTED_LANGS` 加一行
    （选择器按该表顺序，已加载校验；注意服务端 `server.language`
    目前只接受 `zh-CN`/`en-US`，主机侧有显式守卫）。
  - TUI 全部 chrome（状态栏/搜索框/侧栏/输入框/提示/复制/报错）跟随会话语言。
- **按键延迟**：欢迎屏退出 600ms 与开场动画 1100ms 期间输入是锁定的
  （`locked` 期间打字一律忽略），叠加约 1.7s 才可操作。
  - 开场动画**任意键可跳过**（`skip_boot_anim`），直接跳到终态；
  - 欢迎屏是**单层循环**（`welcome_should_exit` 纯谓词，有单测）：退出动画
    播完直接交棒，画前再查一次——终帧全黑就不画，不闪黑屏；
  - 欢迎屏帧节流用 `next_frame_interval`：帧间隔不短于上次实际写耗时，
    终端解析慢时自动降帧而不堆积延迟（写终端是阻塞的，固定节奏补帧
    会让循环卡在 paint 里、到不了 `event::poll`）；
    另注意输出侧洪水也会饿死输入：欢迎屏整屏真彩重绘在 60fps 下约
    2–3MB/s，RustRover 运行窗口等软件终端模拟器解析+渲染跟不上时，
    按键会被淹没好几秒（进程侧 poll/draw 一切正常、背景也在漂，只是
    字节送不到进程）。所以欢迎屏取 30fps（`WELCOME_FRAME_MS=33`），
    输出减半；排查时可用 `SC_CONSOLE_WELCOME_TRACE=<路径>` 记录
    poll/排空/绘制三段耗时；
  - 欢迎屏期间**鼠标捕获是关的**（控制台接手前才开）：欢迎屏只认按键，
    从源头就没有鼠标洪水；残余的缩放洪水由 `drain_frame_events` 整帧排空；
  - 主循环单帧有界排空（`MAIN_DRAIN_MAX=64`）：拖窗口的 Resize 洪水/
    滚轮爆发再多，按键也只延迟一帧，分支与原来逐字相同。
  开关：`SC_CONSOLE_WELCOME=0` 关，或代码侧
  `ConsoleConfig { welcome: false, ..Default::default() }`；
  欢迎期间日志在通道内堆积（有界，满则丢弃计数），进入后照常显示；
  `Ctrl+C` 同样视为进入（之后仍需二次确认才会停止，不误关服）。
- **按键后加载**：GUI + 欢迎屏开启时，宿主在组装完 App 后阻塞等用户按键，
  世界/存档/网络监听等重加载一律推迟到按键之后（`welcome_done` 门控）；
  非交互模式（纯文本/关闭/宿主接管）或 `SC_CONSOLE_WELCOME=0` 直接放行；
  自动化/守护进程启动务必关闭欢迎屏，否则 TTY 下会一直等待按键。
- **开场**（约 1.1s，可开关）：先清屏，标题栏两行与输入框五行底条
  并行自左向右缓动伸展（easeOutCubic）到边缘；伸满后第一行标题打字机
  （`⬢ SculkBedrock <版本>` 逐字出现）与 CPU/MEM 同步渐显，
  输入框波纹内容同步渐显（不等标题播完），可见日志自上而下逐行打出
  （开场结束/关闭后日志恢复正常整行显示，之后的不用打字机）；播完无缝切入
  常规启动态（最后一帧可见文本与稳态完全一致，无跳变）。
  开关：`SC_CONSOLE_BOOT_ANIM=0` 关（`1/true/on/yes` 开，默认开），
  或代码侧 `ConsoleConfig { boot_anim: false, ..Default::default() }`；
  开场播完前到来的启动成功会暂缓横扫（两者串行，不打架）。

- **启动中**：`❯` 不显示；第 3 行居中启动文案，青灰连续渐变双环自中心向外扩展，按输入框宽度覆盖到最远角落，渐变尾带完全退出后循环；前 0.5 秒保持 15% 亮度，随后 1 秒平滑提亮；输入锁定（Ctrl+C 停止与滚动可用）；动画约 60fps，仅刷新变化的行。
- **横扫**（约 900ms）：一条绿色渐变亮带自左向右扫过输入框，扫过位置留下淡绿底色，横扫结束时恢复灰底；
  标题由蓝渐变为绿；`❯` 自窗口边缘滑入左侧并渐显；
  标题变绿后扫光自左向右逐字提亮，再回到稳态浅蓝；
  横扫结束输入框留淡绿底，约 800ms 褪去（与庆祝并行，不阻塞输入）；
- **庆祝**（横扫后约 2.0s，不阻塞输入）：复用版本包脚注行——
  版本包快隐（150ms）→ 0.5s 内缓动收拢为 `>STARTUP<`（相邻字符格亮度交叉过渡）
  → 停留 1s（扫光自左向右逐字提亮，版本包同步显现，共存左/中）→ 渐隐。
- **连续渐变底色**：横扫和波纹以平滑曲线连续混合峰值与灰底，
  用 `\x1b[48;2;R;G;Bm` 真彩输出，需要终端支持 24 位颜色。
  标题呼吸、庆祝扫光/淡出及版本包渐显/渐隐也使用连续 RGB 与 24 位真彩输出；固定色号文字继续使用 256 色。
- **终端刷新**：按行比较前后帧，日志短行和空行清理旧行尾；不先清屏，
  窗口缩放时按实际尺寸刷新，绝对定位与临时禁用自动折行避免滚屏。
  画面与光标一次输出；不支持同步输出的终端（如 macOS Terminal）也只更新变化行。
- **一言打字机**（`Typewriter` 状态机，`src/lib.rs`）：标题第二行一言，
  切换时**先删旧文再打新文**——删除 40ms/字自右向左、打字 80ms/字自左向右（CJK 安全），
  **右括号 `」` 全程钉在行尾不参与变动**；打完后 600ms 内自左向右扫光（逐字高斯提亮后离场），
  随后回到稳态固定色号 117。空文本直接稳态，不播动画。
  每 30 秒轮换一条（API 成功用 API，否则换一条内置兜底）。
- **配色**：自然渐变（中间调可含红分量），只避开薰衣草紫等明确发紫的色号。

## 与架构的关系

- 本 crate **不依赖任何游戏域 crate**（无 `sc_ecs` / `sc_command` / `sc_game` / `sc_world` / `sc_network`）。
  驗證：`grep -r "sc_" src/ Cargo.toml` 应只命中自身与注释。
- **Workers prepare; owners publish**：控制台线程只做终端 IO 与渲染；
  用户输入以 owned `String` 经有界通道交给宿主，由宿主在 tick（owner 上下文）
  里排空并发布为 `RawCommandInput`（`CommandOrigin::Console`）。
- **全部队列有界**（`ConsoleConfig`）：日志通道 / 输入通道 / 日志窗 /
  历史 / 补全列表；满载丢弃并计数展示，不阻塞游戏线程。
- **终端恢复三层保障**：正常 `shutdown()` → `Last` 调度关停系统
  （`sc_bootstrap::console_bridge`，先于 `process::exit` 执行）→ `atexit` 兜底。

## 补全接口

```rust
pub trait CompletionProvider: Send + Sync + 'static {
    fn complete(&self, line: &str, cursor: usize) -> Vec<CompletionItem>;
}
```

- 宿主实现该 trait，`ConsoleHandle::set_provider` 热替换。
- 内置 `StaticCompletionProvider`：基于命令快照（名/别名/描述）前缀补全；
  `sc_bootstrap::console_bridge` 监听 `CommandRegistry::revision`，
  变化时重建快照并推入——插件命令自动出现在补全里。
- Minecraft 式触发（`trigger_at`）：只有输入 `/`（命令位）或 `:`
  （命名空间位）后才弹窗；应用时只替换触发符之后的部分，
  `/` 与 `:` 前缀原样保留（如 `/st` → `/stop`）。
- 弹窗出现动画：约 240ms 自输入框向上逐行弹出（日志逐行上顶，无跳变），
  每行 8 列 easeOutCubic 滑入 + 自黑渐显；播完切回主题色号；
  `↑`/`↓` 选择候选（到顶/到底循环），`Enter` 照常提交、`Tab` 应用补全。
- 参数补全是预留扩展点：`complete` 能看到整行与光标，
  当前内置实现只处理命令位与命名空间位，参数位返回空。

## 运行模式

`SC_CONSOLE` / `SC_CONSOLE_MODE`：`auto | gui | plain | off`（默认 `auto`）。

| 模式 | 行为 |
|---|---|
| `gui` | alternate screen TUI（需 TTY，否则回退 plain） |
| `plain` | 阻塞读 stdin 行，不接管终端 |
| `off` | 不启动线程（宿主 UI 接管输入时用） |
| `auto` | 宿主模式→`off`；TTY→`gui`；否则→`plain` |

## 按键

- `Enter` 提交（恒为提交，可预测）；`Tab` 应用补全（唯一候选自动应用）
- `↑↓` 历史 / 弹窗选择；`Esc` 关闭弹窗或清空行；`PgUp/PgDn` 回看日志
- `Ctrl+F` 查找日志（大小写不敏感，增量高亮全部命中为淡蓝底、当前选中绿底金字；
  选中切换时绿底约 250ms 渐显、文字约 500ms 扫光后回稳态；
  状态行变搜索框并显示 `当前/总数`；`Enter`/`↓`/`Ctrl+F` 下一个，
  `Shift+Enter`/`↑` 上一个；`Esc` 退出并恢复进入时的视图；
  查询变化自动跳到首个命中，新日志到达只重算不抢视图；
  `Ctrl+C` 有查询则清空、否则退出，查找态永不触发关服二次确认）
- `Ctrl+U/K/W/A/E` 行编辑；`Ctrl+L` 清屏
- **空行 `Ctrl+C` / `Ctrl+D` = 二次确认后停止**：第一次只"武装"，状态行
  （输入框下方、原按键提示位置）交叉淡变为淡红底金黄字
  `再按一次 Ctrl+C 关闭服务端`（150ms 渐显，取消/超时 400ms 渐隐，窗口 3s）——
  常规按键提示同时渐隐、药丸渐显，两边都是 RGB 平滑插值，无跳变/空行；
  窗口内第二次才真正停止，`Esc` 取消。确认后向自身发 `SIGINT`：
  raw 模式关掉了终端 ISIG，不 raise 的话宿主信号处理器收不到，
  启动期（命令管线未 tick）将无法退出；raise 后走
  `SHUTDOWN_REQUESTED → SCExit` 原优雅路径（带保存退出，与 TUI 之前一致）
- 鼠标：滚轮滚动日志；日志区拖选松开即复制；单击输入框定位光标
